
GiHub repository and supplementary resources for the manuscript:
"An evolutionary approach to identify mammalian adaptive mutations in the avian influenza polymerase complex."

NOTE:
Project code has been deposited in a new repository for public access. 
Accompanying data can be found in the "Figures/Interactive html files" folder.
File paths and directories have been modified or removed for privacy and data availabilty limitation. 
Due to data governance and sharing permissions we are not able to share sequence data obtained from GISAID, however GISAID IDs can be found for each segment in the file 'Data/GISAID_IDs'.
We thank the authors of all sequences uploaded to GISAID
